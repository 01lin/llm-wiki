# Draft Model Speculation

The classic [[20260608-120000-speculative-decoding-概念]] setup: a separate small model drafts tokens, the large target model verifies. In vLLM it is the `draft_model` method (`DraftModelProposer`). Most flexible (the drafter can be any small model) but the heaviest on memory because it loads extra weights. On vLLM-Ascend the drafter's `draft_tensor_parallel_size` is currently limited to 1.
