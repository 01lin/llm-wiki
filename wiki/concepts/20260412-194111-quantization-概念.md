# Quantization

**Quantization** reduces the numerical precision of model weights and activations (e.g., FP16 to FP8 or FP4), decreasing memory footprint and increasing inference throughput. It is complementary to [[20260412-194030-sparse-attention-概念|Sparse Attention]], which reduces the number of tokens processed.

## Key Ideas

- **FP8** - 8-bit floating point, widely supported, good quality-efficiency tradeoff
- **NVFP4** - NVIDIA's 4-bit format, pushing the precision frontier lower
- [[20260412-194210-vllm-实体|vLLM]]'s llm-compressor enables "quantize once, serve with vLLM" workflow, supporting [[20260412-194210-gemma-实体|Gemma]] 4 and [[20260412-194210-qwen-实体|Qwen]] 3.5
- KV cache quantization is a specific application that reduces the dominant memory bottleneck during inference

## How It Connects

- [[20260412-194030-kv-cache-概念|KV Cache]] - quantizing KV cache reduces the main memory bottleneck
- [[20260412-194030-sparse-attention-概念|Sparse Attention]] - complementary optimization approach
- [[20260412-194210-vllm-实体|vLLM]] - primary serving framework with quantization support
- [[Inference Optimization]] - quantization is one of several approaches

## Counter-arguments

- Lower precision can degrade output quality, especially for reasoning-heavy tasks
- Quantization effects are model-specific - some architectures are more robust than others
