# GRPO

**Group Relative Policy Optimization (GRPO)** is an optimized version of [[20260412-194126-ppo-概念|PPO]] for LLM training that replaces heavy critic models with generating groups of outputs and scoring them against deterministic verifiers. Supports binary (0/1) and continuous rewards. A key enabler of the [[20260412-194111-rlvr-概念|RLVR]] paradigm.

## Key Ideas

- Eliminates value model and reward model from PPO, significantly reducing memory overhead
- Central to scaling reasoning capabilities in modern LLMs
- Works with [[20260412-194210-nemo-gym-实体|NeMo Gym]] environments and training frameworks like [[20260412-194210-unsloth-实体|Unsloth]]

## How It Connects

- [[20260412-194030-reinforcement-learning-概念|Reinforcement Learning]] - parent paradigm
- [[20260412-194111-rlvr-概念|RLVR]] - paradigm it enables
- [[20260412-194126-ppo-概念|PPO]] - predecessor algorithm
- [[20260412-194126-dpo-概念|DPO]] - alternative approach (no RL loop)
