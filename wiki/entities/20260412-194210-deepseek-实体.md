# DeepSeek

**DeepSeek** is a Chinese AI lab developing the DeepSeek model family. DeepSeek-V3.2 uses [[20260608-125000-deepseek-sparse-attention-dsa-概念|DeepSeek Sparse Attention (DSA)]], supported by [[20260412-193923-hisparse-turbocharging-sparse-attention-with-hierarchical-memory-来源|HiSparse]] for optimized inference.

## DeepSeek-V4 (2026)
DeepSeek-V4 ships in **Flash** (hidden 4096, 43 layers, index_topk 512) and **Pro** (hidden 7168, 61 layers, index_topk 1024) variants, both using DSA with per-layer `compress_ratios` (C4/C128) and an MoE backbone (256 / 384 routed experts). Pro is blocked on vLLM-Ascend by a 512 Top-K operator cap - see [[20260608-125100-deepseek-v4-pro-vllm-ascend-gap-analysis-来源]]. DeepSeek also maintains [[20260608-122855-deepgemm-实体|DeepGEMM]] (FP8/FP4 kernels, Mega MoE) and the `dflash` MTP path ([[20260608-121300-dflash-概念]]).
