# NVIDIA

**NVIDIA** develops GPU hardware and AI infrastructure. Key frameworks: [[NeMo Gym]] (RL environments), NeMo RL (training), NeMo Data Designer (synthetic data). Developed Nemotron 3 model family using structured RL. Hardware: H200, H20, DGX Spark, upcoming Grace Blackwell.
