# TileRT

**TileRT** is a **tile-level native runtime** for ultra-low-latency, single-request LLM decode (millisecond TPOT), aimed at high-frequency interaction, real-time decision, long-horizon agents, and AI coding. Pre-built for **8x NVIDIA B200**; models DeepSeek-V3.2 and GLM-5. Reported: up to 600 tok/s (DeepSeek-V3.2), 500 (GLM-5-FP8), 590 (v0.1.2-alpha MTP=3 synthetic); MTP mean accept length ~2.77.

## Open-source boundary
The Python layer is only a **control plane + fixed ABI**: model structure description, weight conversion, fixed-ABI buffer prep, and wrappers calling `torch.ops.tilert.*` from the **closed `libtilert.so`**. The real tile-level scheduling, graph capture, and kernels live in the native library (no `.cu/.cpp` in the repo). Key native entry points: `dsa_show_hands_prepare_money` (register/capture runtime) and `dsa_show_hands` (decode step).

## Core design (transferable)
Implements [[20260608-133500-runtime-elimination-fixed-decode-概念|runtime elimination]]: a fixed `temp_vars` ABI (51 slots: Q/KV/KI, logits, token, cur_pos, draft/predicted/accepted/next_draft, FP8 quant, sampling config), continuous-storage buffers (address-stable, 1024-byte aligned) for native graph replay, offline weight conversion to kernel-friendly layouts (MMA swizzle, FP8/FP16/BF16), heavily fused ops (RMSNorm+proj+quant, expert select+up/gate+SiLU, down+allreduce, head+sampling), and **device-side MTP** as part of the runtime state machine. Fixed `num_devices=8`, `batch_size=1`.

## Trade-offs
Gives up: general model support, dynamic batching, multi-tenant serving, dynamic sampling params (baked into the captured plan), hardware independence. Gains: minimal decode hot-path overhead, deep model/hardware-specific fusion, stable native replay, MTP-native acceleration. Compare with [[20260412-194210-vllm-实体]], [[20260412-194210-sglang-实体]], [[20260608-131000-tokenspeed-实体]] (both are agentic/low-latency engines; TokenSpeed keeps a Python+C++ scheduler, TileRT goes fully native). Its ideas drive the [[20260608-133100-vllm-ascend-tilert-like-self-evolving-loop-来源|TileRT-like Ascend loop]].
