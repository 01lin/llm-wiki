# GLM

**GLM** is Zhipu AI's LLM family. GLM-5.1 uses [[Sparse Attention|DeepSeek Sparse Attention]] and is supported by [[lmsys-2026-hisparse|HiSparse]] via [[SGLang]] for optimized inference with up to 5x throughput gains.
