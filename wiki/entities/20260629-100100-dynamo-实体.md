# Dynamo (NVIDIA ai-dynamo)

NVIDIA 开源推理服务编排框架，router/engine 解耦架构。在 [[20260628-150300-agentic-inference-engine-cooptimization-概念]] 中作为参考实现。

## Agent Hints 机制

- **请求体 `nvext.agent_hints`（4 字段）**：`priority`（下沉 SGLang 排队）、`strict_priority`（router only）、`osl`（router only）、`speculative_prefill`（预热触发）
- **HTTP header 会话身份**：`X-Dynamo-Session-ID`、`X-Dynamo-Session-Final`（SGLang 当前版本未处理）

## 关键局限（= 协同优化空间）

只下沉了 `priority`（调度+逐出）和 `session ID`（KV 打标签）两类窄信号；所有高价值的时序/结构/关系维信号都停在 router 层，未进引擎。传的都是标量先验，而非 agent 执行计划。

源码锚点（v1 方案 §0 坐实）：`lib/llm/src/preprocessor/speculative_prefill.rs`、`kv_router.rs` 已存在 `agent_hints` / `speculative_prefill` / `strict_priority`。

## Data gaps

- Dynamo 与 vllm-ascend（非 SGLang）的对接路径未验证
- agent_hints 端到端透传到引擎调度器/KV manager 的完整链路待确认
