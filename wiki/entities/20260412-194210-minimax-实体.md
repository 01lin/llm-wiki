# MiniMax

**MiniMax** is a Chinese AI company developing the M2 model series. M2.7 is positioned as the first model deeply participating in its own evolution via [[20260412-194111-self-evolving-ai-概念|Self-Evolving AI]] workflows. Offers MiniMax Agent platform and API access. Also developed OpenRoom for interactive entertainment.
