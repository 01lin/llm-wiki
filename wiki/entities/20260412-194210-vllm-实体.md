# vLLM

**vLLM** is a widely-used open-source LLM serving framework. Known for PagedAttention (efficient KV cache memory management) and the llm-compressor tool for [[20260412-194111-quantization-概念|Quantization]] (NVFP4, FP8). Supports [[20260412-194210-gemma-实体|Gemma]] 4 and [[20260412-194210-qwen-实体|Qwen]] 3.5.
