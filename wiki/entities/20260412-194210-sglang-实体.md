# SGLang

**SGLang** is an LLM serving framework developed by [[20260412-194210-lmsys-实体|LMSYS]], implementing RadixAttention for KV cache reuse, HiCache for hierarchical caching, and [[20260412-193923-hisparse-turbocharging-sparse-attention-with-hierarchical-memory-来源|HiSparse]] for sparse attention optimization. Supports [[20260412-194111-prefill-decode-disaggregation-概念|Prefill-Decode Disaggregation]].

## Ascend NPU support
SGLang runs on Huawei Ascend (A2/A3) via [[20260608-125400-sgl-kernel-npu-实体|sgl-kernel-npu]], a kernel library plugged in through SGLang's Platform plugin system (no fork). Drafter training is handled by [[20260608-123100-specforge-实体|SpecForge]]. NPU spec decoding uses `NEXTN` (MTP-style). See [[20260608-125300-sglang-ascend-deployment-perf-来源]] for deployment + perf data.
