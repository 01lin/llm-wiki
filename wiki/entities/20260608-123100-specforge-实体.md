# SpecForge

**SpecForge** (`sgl-project/SpecForge`) is the [[20260412-194210-sglang-实体]] project's open-source framework for **training speculative-decoding drafters** - EAGLE-3 and [[20260608-121300-dflash-概念]]. Trained weights are served via SGLang. As of early 2026, its DFlash training path is reverse-engineered from the official z-lab/dflash inference code (ZLab hasn't released training details), leading to reproducibility issues with low acceptance length (see [[20260608-123000-specforge-dflash-low-acceptance-bug-455-来源]]). Key alignment knobs: chat template, loss (CE vs KL), `mask_token_id`, `target_layer_ids`.
