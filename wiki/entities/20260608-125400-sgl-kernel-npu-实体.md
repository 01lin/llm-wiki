# sgl-kernel-npu

The Ascend NPU kernel library for [[20260412-194210-sglang-实体]] - a separately published whl plugged into SGLang via its Platform/plugin system (`torch.ops.npu`, PrivateUse1 dispatch), the NPU counterpart of `sgl-kernel` (GPU). Built with **AscendC** (high-perf kernels), **Triton** (Python-side fused kernels), and **CATLASS** (Huawei's CUTLASS). Two subsystems: **DeepEP-Ascend** (MoE expert-parallel All-to-All over HCCS; A3 full-mesh, A2 HCCS+RDMA; Low-Latency mode sub-150us) and the kernel lib (Paged MLA/GQA, end-to-end fused MLA preprocess, LoRA, speculative tree build/verify, Flash Linear Attention / gated delta rule, lightning indexer for DSA). See [[20260608-125200-sglang-vs-sgl-kernel-npu-对比分析-来源]]. Sibling to [[20260608-122850-vllm-ascend-实体]] in the Ascend serving ecosystem.
