# MindSpeed-LLM

**MindSpeed-LLM** is Huawei's Megatron/mcore-style **LLM training framework for Ascend NPU** (the training counterpart to [[20260608-122850-vllm-ascend-实体|vLLM-Ascend]]'s inference). It currently implements **DeepSeek-V4-Flash** fixed-length pretrain (preview status; full fine-tune and CP marked DOING), with code paths reusable for [[20260412-194210-deepseek-实体|DeepSeek]]-V4-Pro.

## DeepSeek4 model stack
`DeepSeek4Model` + `deepseek4_spec`, built per layer as: MHC pre -> RMSNorm -> **G2 sparse shared-KV attention** (linear_q/kv are LinearNoTP/TP-replicated; q_up_proj/o_proj are Column/Row TP; [[20260608-125000-deepseek-sparse-attention-dsa-概念|DSA indexer]] when compress_ratio=4, compressor when >1) -> MHC post -> MHC pre -> MoE MLP (router top-6 + shared + routed experts, all-to-all dispatch, grouped GEMM) -> MHC post. Final stage: hc_head -> MTP -> final norm -> vocab head. SFT via `posttrain_gpt.py` -> `DeepSeek4SFTTrainer`; `deepseek4` prompt template handles thinking/tool-calling tokens.

## Pipeline-parallel toolbox
Plain non-interleaved 1F1B (Flash SFT default, PP=4), VPP/interleaved 1F1B, **DualPipeV** (bidirectional), RiPipe (recompute-in-advance), noop layers (pad layer count for even PP split), num-layer-list (uneven split), U-shape Layerwise Disaggregated Training (Qwen-only, no MoE). See [[20260608-134100-mindspeed-llm-deepseek4-sft-pp-parallel-来源]].

## Why MHC matters for PP
[[20260608-134300-mhc-multi-head-channel-概念|MHC]] (`--enable-mhc`, hc_mult=4) changes inter-stage activation from `[S,B,H]` to `[S,B,hc,H]`, so MindSpeed patches `get_tensor_shapes` (and the interleaving schedule under VPP). Any new PP/VPP/DualPipeV combo must first pass a single-step shape/comm check.

Relates to [[20260608-125100-deepseek-v4-pro-vllm-ascend-gap-analysis-来源]] (the inference-side V4 gap), [[20260608-121100-mtp-multi-token-prediction-概念]].
