# vLLM

**vLLM** is a widely-used open-source LLM serving framework. Known for PagedAttention (efficient KV cache memory management) and the llm-compressor tool for [[Quantization]] (NVFP4, FP8). Supports [[Gemma]] 4 and [[Qwen]] 3.5.
