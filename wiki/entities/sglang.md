# SGLang

**SGLang** is an LLM serving framework developed by [[LMSYS]], implementing RadixAttention for KV cache reuse, HiCache for hierarchical caching, and [[lmsys-2026-hisparse|HiSparse]] for sparse attention optimization. Supports [[Prefill-Decode Disaggregation]].
