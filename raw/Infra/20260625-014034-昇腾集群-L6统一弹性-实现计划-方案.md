from vllm_ascend.core.scheduler_dynamic_batch import SchedulerDynamicBatch

class SchedulerGoodput(SchedulerDynamicBatch):
    def schedule(self):
        # 在父类 schedule 前，按 P/D 角色 + 当前 goodput 调整准入
        self._adjust_admission_by_goodput()
        return super().schedule()

    def _adjust_admission_by_goodput(self):
        # goodput = 满足 TPOT SLO 的有效吞吐（辅口径 C）

        waiting = len(self.waiting); running = len(self.running)
        if self._tpot_near_slo() and waiting > 0:
            self.max_num_running_reqs = max(1, running)  # 不再纳新，保 TPOT
        # 复用已有 BudgetRefiner 的 SLO 查表（已坐实 :72）

## 遗留问题（要求1，诚实标注边界）

1. **扩缩期 KV 不丢 + 在途请求 drain**：T4 改 replicas 时，被摘实例的 KV 与在途请求如何处理？依赖 PD connector 的 KV 迁移能力 + drain 机制，**vllm-ascend 是否支持优雅摘除未坐实**。❓ 这是 L6b 最大风险。
2. **整机弹性是否依赖 K8s 外部层** — 坐实 Volcano/Kthena replicas 静态，autoscale 逻辑须外建（本计划 T2-T5）。✅ 边界已划清
3. **goodput SLO 阈值** — BudgetRefiner 的 SLO 查表需填昇腾实测 cost 表(_read_lookup_table:54 读 csv)。❓
4. **P/D 配比调整粒度** — 整节点 vs 单卡，依部署拓扑。❓
5. **L6 收益依赖 L1** — L1 命中后 prefill 锐减使 P/D 漂移更剧烈，L6 价值随 L1 放大（推导 §2.3 注）。✅
