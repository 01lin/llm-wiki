## 三、核心类定义（新建模块的代码骨架）

### 3.1 SpecRuntimeState（runtime_state.py，新建）

```python
@dataclass
class SpecRuntimeState:
    """动态投机 Shape 单一事实源。所有 draft_len/shape/graph 状态只由此生成。"""
    active_k: int                 # 本轮实际 draft 长度（DraftLenPolicy 决定）
    max_k: int                    # 容量上界 = speculative_config.num_speculative_tokens

    # ---- 派生（唯一来源，禁止其他模块重推导）----
    @property
    def active_D(self) -> int:    # target verify 每 req token 数
        return self.active_k + 1
    @property
    def graph_spec_k(self) -> int:
        return self.active_k

    # ---- batch / graph / feedback ----
    num_reqs: int = 0
    num_tokens: int = 0
    uql: int = 1                  # uniform decode query len = active_D
    graph_mode: str = "FULL"      # FULL/PIECEWISE/NONE
    graph_key: tuple | None = None
    fallback_hit: bool = False
    accept_rate: float | None = None

    # ---- 更新接口（adapter 调用，对照真实调用链）----
    def update_from_scheduler(self, scheduler_output): ...   # step1
    def update_from_proposer(self, real_draft_len): ...      # step8
    def update_graph_status(self, mode, key): ...            # step4
    def update_from_acceptance(self, num_accepted): ...      # step6
```

### 3.2 DraftLenPolicy（policy.py，新建）

```python
class DraftLenPolicy(ABC):
    @abstractmethod
    def select(self, rt: SpecRuntimeState, scheduler_output) -> int: ...  # 返回 active_k

class StaticDraftLenPolicy(DraftLenPolicy):       # = 现有静态行为，fixed_k
    def select(self, rt, _): return rt.max_k

class BatchDynamicPolicy(DraftLenPolicy):         # 按 batch_size 选（对照 SGLang bs_entries）
    def __init__(self, candidates: dict[int, int]): ...
    def select(self, rt, _): return self.candidates.get(rt.num_reqs, rt.max_k)

class FeedbackPolicy(DraftLenPolicy):             # 按 accept_rate（异步，不新增同步）
    def select(self, rt, _): return self._from_accept_rate(rt.accept_rate)
```

## 五、核心不变量（开发自检 + 验收）

```text
active_D = active_k + 1 必须在同一轮取同值：
  query_start_loc / decode_token_per_req / num_scheduled_tokens / num_draft_tokens
  / spec_state_indices.size(-1)（GDN） / spec_multiple（DSA） / num_accepted上界 / graph_key
任一停留在静态 max_k → GDN 精度异常 / DSA 布局错位
```

**验收标准**（三原则）：
1. Shape 单一事实源：上述变量只由 SpecRuntimeState 生成。
2. 稳态零开销：fixed_k=static baseline 时 no-op fast path，TPOT 不劣化。
3. patch 最小：复用 proposer 工厂/多继承，改造集中在 RuntimeState 消费点。
